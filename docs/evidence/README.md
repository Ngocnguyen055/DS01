# Bằng chứng demo

Thư mục này chỉ chứa log, ảnh hoặc số đo thực sự thu được. Với mỗi lần demo, ghi:

- ngày giờ và múi giờ;
- commit Git;
- OS, phiên bản Node và trình duyệt;
- peer/mạng được dùng;
- lệnh chạy;
- kết quả quan sát và giới hạn.

`benchmark.txt` là phép đo localhost đã có. Cần đo lại và lưu file mới nếu môi trường demo thay đổi.
